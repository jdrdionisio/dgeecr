# Catalogo de regioes de saude 2024

Catalogo de regioes de saude 2024

## Usage

``` r
dgeec_regioes_saude(geo = NULL)
```

## Arguments

- geo:

  Tabela de ligacao (por omissao
  [`dgeec_geo()`](https://jdrdionisio.github.io/dgeecr/reference/dgeec_geo.md)).

## Value

Um `tibble` com `regiao_2024`, `n_municipios` e `municipios`.
