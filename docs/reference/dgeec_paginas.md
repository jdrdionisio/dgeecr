# Catalogo de paginas disponiveis

Devolve o conjunto de paginas (tabelas) publicadas no portal.

## Uso

``` r
dgeec_paginas()
```

## Valor

Um `tibble` com as colunas `id`, `grupo`, `path` e `descricao`.
