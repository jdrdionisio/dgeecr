# Catalogo de ULS (2024)

Catalogo de ULS (2024)

## Uso

``` r
dgeec_uls(geo = NULL)
```

## Argumentos

- geo:

  Tabela de ligacao (por omissao
  [`dgeec_geo()`](https://jdrdionisio.github.io/dgeecr/reference/dgeec_geo.md)).

## Valor

Um `tibble` com `uls`, `regiao_2024`, `n_municipios` e `municipios`.
