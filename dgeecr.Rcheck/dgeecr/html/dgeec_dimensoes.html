dgeec_dimensoes {dgeecr}R Documentation

Dimensoes (filtros) de uma pagina

Description

Le a pagina do portal e devolve os valores possiveis de cada ⁠<select>⁠, com o respetivo nivel hierarquico (no caso das regioes).

Usage

dgeec_dimensoes(pagina, timeout = 45L)

Arguments

pagina

Id de pagina (ver dgeec_paginas()) ou o respetivo path.

timeout

Timeout por pedido, em segundos.

Value

Um tibble com select, codigo, rotulo e nivel.

Examples


dgeec_dimensoes("pre_escolar")
