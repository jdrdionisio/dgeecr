enriquecer_geo {dgeecr}R Documentation

Enriquece dados DGEEC com divisoes administrativas e de saude

Description

Liga as linhas de nivel "Municipio" ao ficheiro de ligacao geografica e acrescenta uls_1, uls_2, uls_principal, n_uls, regiao_2024, nuts1, nuts2, nuts3, aces_2022 e ars_2022. Municipios com varias ULS (Lisboa, Porto, Gondomar, Loures, Funchal) ficam com uls_1/uls_2.

Usage

enriquecer_geo(dados, geo = NULL)

Arguments

dados

Um tibble produzido por DgeecClient⁠$dados()⁠ / dgeec_dados(), com as colunas regiao_codigo, regiao_nome e regiao_tipo.

geo

Tabela de ligacao (por omissao dgeec_geo()).

Value

dados com as colunas geograficas acrescentadas.
