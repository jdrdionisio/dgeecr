dgeec_dados {dgeecr}R Documentation

Extrair dados de uma pagina (atalho)

Description

Cria um DgeecClient e extrai os dados de uma pagina.

Usage

dgeec_dados(pagina, ..., cliente = NULL)

Arguments

pagina

Id de pagina (ver dgeec_paginas()).

...

Argumentos passados a DgeecClient$dados() (p.ex. regioes, natureza, incluir_totais).

cliente

Um DgeecClient opcional.

Value

Um tibble longo.

Examples


dgeec_dados("pre_escolar", regioes = "0")
