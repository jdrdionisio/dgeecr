dgeec_geo {dgeecr}R Documentation

Tabela de ligacao municipio -> divisoes administrativas e de saude

Description

Le o ficheiro de ligacao geografica incluido no pacote (inst/extdata/geo_linkage_2024_v8.csv) e agrega-o ao nivel do municipio, resolvendo as ULS que dividem um municipio ao nivel da freguesia em uls_1 e uls_2.

Usage

dgeec_geo(path = NULL)

Arguments

path

Caminho alternativo para o CSV de ligacao.

Value

Um tibble por municipio.
