DgeecClient {dgeecr}R Documentation

Cliente DGEEC

Description

Cliente R6 para o portal "Regioes em Numeros - Educacao". Gere a paralelizacao (httr2), o cache em disco (com resume) e a conversao em tabela longa.

Public fields

cache_dir

Pasta de cache (NULL = tools::R_user_dir("dgeecr","cache")).

concorrencia

No de pedidos simultaneos.

timeout

Timeout por pedido (s).

tentativas

Tentativas por pedido.

usar_cache

Reutilizar HTML ja descarregado?

lote

No de pedidos por lote.

DgeecClient$dados()

Extrai dados de uma pagina.

Usage
DgeecClient$dados(
  pagina,
  regioes = NULL,
  natureza = NULL,
  genero = NULL,
  orientacao = NULL,
  incluir_totais = FALSE,
  progress = TRUE
)
Arguments
pagina

Id de pagina (ver dgeec_paginas()).

regioes

Vetor de codigos de regiao (NULL = todas).

natureza

Codigos de natureza (NULL = desagregado 1/2, ou todos se incluir_totais).

genero

Codigos de genero (NULL = desagregado 1/2, ou todos se incluir_totais).

orientacao

Codigos de orientacao (NULL = desagregado 10/20, ou todos se incluir_totais).

incluir_totais

Incluir tambem os niveis totais (0/...)?

progress

Mostrar progresso.

Returns

Um tibble longo (1 linha = 1 observacao).
