agregar_uls {dgeecr}R Documentation

Agrega dados ao nivel da ULS

Description

Soma os valores dos municipios pertencentes a cada ULS.

Usage

agregar_uls(dados, geo = NULL, multiplas = c("excluir", "duplicar", "maior"))

Arguments

dados

tibble de DgeecClient⁠$dados()⁠.

geo

Tabela de ligacao (por omissao dgeec_geo()).

multiplas

Como tratar os municipios repartidos por varias ULS (Lisboa, Porto, Gondomar, Loures, Funchal), cujos dados o portal so publica ao nivel do municipio: "excluir" (por omissao) remove-os da soma e lista-os no atributo municipios_excluidos; "duplicar" atribui o valor a cada ULS (dupla contagem); "maior" atribui a ULS com mais freguesias.

Value

Um tibble ao nivel da ULS (+ atributo municipios_excluidos).
